# RetailPro

### Retail Management & Inventory System

**Developed By:** Bikramjeet Singh
**Course:** B.Tech – Computer Science Engineering
**College:** Rayat Bahra University

## 1. Project Overview

RetailPro is a desktop-based Retail Management and Inventory System developed using Python and MySQL. It helps users manage products, customers, inventory, orders, payments and sales reports efficiently.

## 2. Technologies Used

- Python
- Tkinter (Graphical User Interface)
- MySQL (Database Management)
- MySQL Connector for Python

## 3. Main Features

- Dashboard for overview
- Product Management
- Add and Update Stock
- Customer Management
- Place Customer Orders
- Payment Management
- Order Status Management
- Sales Reports
- Low Stock Alerts

## 4. Project Modules

1. Dashboard
2. Products
3. Customers
4. Place Order
5. All Orders
6. Reports

## 5. Database

**Database Name:** StoreSphere

The database stores information about products, customers, orders, order items and payments.

## 6. Installation & Execution

1. Install Python.

2. Install MySQL Server.

3. Install the required Python library:

   `pip install mysql-connector-python`

4. Create the required MySQL database and tables using the provided SQL files.

5. Configure your MySQL connection settings in the Python application.

6. Run the application:

   `python Shopping_app2.py`

## 7. Project Purpose

The main purpose of RetailPro is to simplify retail store operations, maintain accurate inventory records and manage customer orders efficiently.

## 8. Future Scope

- Online payment integration

## 9. Conclusion

RetailPro provides a simple and efficient way to manage retail operations using Python and MySQL.
